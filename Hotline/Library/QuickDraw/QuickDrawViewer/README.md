# QuickDrawViewer

The PICT decoder and renderer from Matthias Wiesmann's QuickDraw Viewer,
https://github.com/wiesmann/QuickDrawViewer, copied unmodified from commit
`aac7fa4` (aac7fa4bb87d360ae305a8f6ed0c295993106a3c). It's licensed under the
Apache License 2.0; see QuickDrawViewer-License.txt (the repo's License.txt,
renamed so it's clear in the app bundle).

To update, copy the same files from the `QuickDrawViewer` folder of a newer
commit. The app's UI files (the `UI` folder) aren't needed. Hotline's own code
for PICT previews is in PICTImage.swift, one folder up.
